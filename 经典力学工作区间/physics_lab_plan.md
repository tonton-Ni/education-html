# Python 经典力学实验室：可调参数、模型计划与编写方法

## 一、总体结构

所有实验拆成五层：

1. **物体**：质点、小球、滑块、圆盘。
2. **力与场**：重力、弹力、摩擦力、空气阻力。
3. **约束**：绳子、轻杆、斜面、滑轮。
4. **边界**：地面、墙壁、桌子。
5. **测量与显示**：时间、位置、速度、加速度、能量和图像。

统一使用国际单位制：m、kg、s、N、J。

## 二、可调部分

### 1. 全局参数

| 参数 | 符号 | 默认值 | 用途 |
|---|---:|---:|---|
| 重力加速度 | `g` | 9.8 m/s² | 模拟地球、月球或无重力 |
| 时间步长 | `dt` | 0.001 s | 控制数值计算精度 |
| 播放速度 | `speed` | 1.0 | 慢放或加速，不改变真实物理时间 |
| 空气阻力系数 | `drag_k` | 0 | 比较理想运动与受阻运动 |
| 是否暂停 | `paused` | `False` | 观察某一时刻的状态 |

### 2. 物体参数

- 质量 `mass`
- 初始位置 `x, y`
- 初始速度 `vx, vy`
- 半径 `radius`
- 恢复系数 `restitution`：0 为完全不弹性，1 为完全弹性
- 摩擦系数 `mu`

### 3. 模型专用参数

| 模型 | 主要可调参数 |
|---|---|
| 自由落体 | 初始高度、`g`、空气阻力 |
| 平抛运动 | 初始高度、水平初速度、`g` |
| 斜面滑块 | 倾角 `theta`、摩擦系数 `mu`、质量 |
| 弹簧振子 | 劲度系数 `k`、原长、初始位移、阻尼 |
| 单摆 | 摆长 `L`、初始角度、`g`、阻尼 |
| 小球碰撞 | 两球质量、初速度、恢复系数 |
| 圆周运动 | 半径、角速度、绳长 |
| 圆周滚动物体 | 半径、质量、转动惯量 |
| 点电荷扩展 | 电荷量 `q1, q2`、距离、库仑常数 |

### 4. 交互方式

第一阶段直接用 Python 变量调参；第二阶段增加滑块和按钮：

- 滑块：质量、角度、初速度、弹性、摩擦、摆长、弹簧劲度。
- 按钮：开始、暂停、单步、重置。
- 开关：显示速度矢量、力矢量、轨迹、能量曲线。
- 原则：**滑块只改参数，不直接改物理公式。**

## 三、模型开发计划

### 阶段 1：最小运动引擎

实现：质点、重力、时间推进、轨迹显示。

验收：自由落体满足 `y = y0 + v0*t - 0.5*g*t**2`，平抛轨迹为抛物线。

### 阶段 2：碰撞与边界

实现：地面、墙壁、恢复系数、小球碰撞。

验收：无能量损失时，弹性碰撞前后总动能近似不变。

### 阶段 3：斜面与摩擦

实现：斜面约束、支持力、静摩擦和动摩擦。

验收：光滑斜面加速度 `a = g*sin(theta)`；斜面实验可反推 `mu`。

### 阶段 4：弹簧与振动

实现：胡克定律、阻尼、位移图像和能量转换。

验收：无阻尼时机械能近似守恒，周期随 `m/k` 改变。

### 阶段 5：单摆与圆周运动

实现：绳长约束或极坐标、角度、角速度。

验收：小角度单摆周期接近 `T = 2*pi*sqrt(L/g)`。

### 阶段 6：综合实验

组合已有模型：多球碰撞、弹簧连接、斜面与碰撞、双摆。

### 阶段 7：电磁扩展

加入点电荷和库仑力。电荷不属于经典力学，但可复用同一个运动引擎。

## 四、编写方法

### 1. 用数据类保存状态

```python
from dataclasses import dataclass

@dataclass
class Particle:
    mass: float
    x: float
    y: float
    vx: float = 0.0
    vy: float = 0.0
    radius: float = 0.05
    restitution: float = 1.0
```

**位置、速度表示状态；力表示这一时刻受到的作用。** 不把公式写死在物体类里。

### 2. 每个时间步分四步

```text
清空并计算合力 F
→ 用 a = F / m 求加速度
→ 更新速度和位置
→ 处理碰撞与约束，记录数据
```

基础版本使用半隐式欧拉法：

```python
def step(p, dt, g=9.8):
    p.vy -= g * dt       # 先更新速度
    p.x += p.vx * dt     # 再用新速度更新位置
    p.y += p.vy * dt
```

它比“先更新位置”的简单欧拉法更适合振动和长期模拟。固定 `dt`；动画播放速度只改变绘制频率。

### 3. 力与约束分开写

- 重力、弹簧力、摩擦力：返回力或加速度。
- 地面和墙：检查是否越过边界，再修正位置与法向速度。
- 绳子和斜面：限制物体可运动的方向，不只贴一张图。

```python
def collide_ground(p, ground_y=0.0):
    if p.y - p.radius < ground_y:
        p.y = ground_y + p.radius
        if p.vy < 0:
            p.vy = -p.vy * p.restitution
```

### 4. 绘制与物理计算分离

建议先用 `matplotlib`：物理循环只负责计算，绘图函数只读取状态。世界坐标使用米，避免把像素直接写进公式。

### 5. 每加一个模型就做守恒与极限测试

- `g = 0` 且无外力：速度应保持不变。
- `restitution = 1`：理想弹性碰撞能量近似守恒。
- `theta = 0`：水平面上没有重力沿斜面分量。
- 减小 `dt`：结果应更稳定，而不是明显改变实验结论。
- 数值模拟允许微小误差，不要求浮点数完全相等。

## 五、推荐项目结构

```text
physics_lab/
├── core.py        # Particle、时间推进、公共参数
├── forces.py      # 重力、弹力、阻力、摩擦力
├── constraints.py # 地面、墙、绳、斜面
├── experiments.py # 各实验的初始化和参数
└── main.py        # 动画、按钮、滑块、曲线
```

先写通自由落体和平抛，再添加碰撞、斜面、弹簧、单摆；不要一开始就同时制作所有模型。
